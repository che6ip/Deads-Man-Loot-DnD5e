# Dead's Man Loot — D&D 5e

Адаптер **D&D 5e** для базового модуля **Dead's Man Loot** (`deads-man-loot`).

Передаёт базе системные значения D&D 5e и добавляет слой прав доступа через Мастера, чтобы
игроки могли обыскивать трупы, даже если у них нет прав на актёра.

## Возможности

- Определяет, какие предметы D&D 5e можно забрать из трупа: оружие, снаряжение, расходники,
  инструменты, лут, контейнеры и рюкзаки.
- Считает количество и редкость предметов.
- Распознаёт смерть по статусам «Мёртв» и «Кровоточит», флагу `isDead`, нулю хитов, а также по
  посмертным статусам, повешенным прямо на токен.
- Добавляет кнопку **«Шанс выпадения»** в шапку карточки предмета (только для Мастера).
- Выдаёт игроку временный доступ к трупу на время открытого окна добычи и снимает его после
  закрытия или воскрешения существа.
- Кэширует список добычи для игроков, у которых нет локальных предметов трупа.
- Переносит предметы и открывает карточки предметов через Мастера, если у игрока нет прав.
- Поддерживает мешочки монет с формулами в описании предмета.

## Установка

1. Установите и включите базовый модуль **deads-man-loot**.
2. Скопируйте папку `deads-man-loot-dnd5e` в `Data/modules/deads-man-loot-dnd5e`.
3. Включите адаптер в настройках мира (**Manage Modules**).
4. Обновите сцену клавишей **F5**.

Требуется система **D&D 5e 4.0+** и активный Мастер.

## Как пользоваться

1. Откройте карточку предмета и нажмите кнопку с процентом в шапке окна, чтобы задать шанс
   выпадения.
2. Доведите существо до 0 хитов или повесьте статус «Мёртв»/«Кровоточит».
3. Дважды кликните по трупу — откроется окно добычи.
4. Нажмите **«Взять»**, чтобы перенести предмет своему персонажу.
5. ПКМ по предмету открывает его карточку.

Для получения предмета у игрока должен быть назначен персонаж (`game.user.character`).

## Настройки

Собственных настроек у адаптера нет. Все параметры добычи и отображения шансов находятся в
базовом модуле **Dead's Man Loot**.

## Совместимость

- Foundry VTT **13+** (проверено на сборке 14.369).
- D&D 5e **4.0+**.
- Требуется базовый модуль **deads-man-loot 1.0.0+**.
- Для игроков нужен активный Мастер.
